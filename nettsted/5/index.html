Et mer energieffektivt hjem

Smarte grep for lavere energibruk og bedre bokomfort

Brukerhistorie

Som huseier ønsker jeg å finne tiltak og støtteordninger for å gjøre boligen mer energieffektiv, slik at jeg kan redusere strømforbruket og få et mer behagelig inneklima.

Hvor kan jeg begynne?

Start med å undersøke hvor boligen bruker mest energi. Tetting rundt vinduer og dører, bedre isolasjon, varmestyring og energieffektive vinduer kan være aktuelle tiltak. Hva som lønner seg, avhenger av boligens alder og tilstand.

Les om aktuelle energitiltak og støtteordninger hos Enova. Sjekk vilkår og søknadskrav før du bestiller arbeid, siden støtteordninger kan endres.

Før du setter i gang

  • Se gjennom strømforbruket og noter når det er høyest.
  • Be om råd fra kvalifiserte fagfolk hvis du vurderer større tiltak.
  • Sammenlign tilbud og ta med både materialer og montering i budsjettet.
  • Undersøk støttevilkår før arbeidet starter.
